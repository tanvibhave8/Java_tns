# Micro-Warehouse Inventory & Fulfillment Hub

## About the Project
Micro-Warehouse Inventory & Fulfillment Hub is a Java Spring Boot application designed to manage warehouse inventory and order processing efficiently. It helps administrators manage products, track stock levels, process customer orders, and generate sales reports.

## Features
- Add and view products
- Manage inventory and replenish stock
- Check low-stock products
- Place and manage customer orders
- View total revenue
- Identify top-selling products

## Technologies Used
- Java
- Spring Boot
- MySQL
- JDBC (JdbcTemplate)
- Maven

## How to Run
1. Clone the repository.
2. Configure MySQL database credentials in `application.properties`.
3. Create the required database.
4. Run the application using:

```bash
mvn spring-boot:run
```
